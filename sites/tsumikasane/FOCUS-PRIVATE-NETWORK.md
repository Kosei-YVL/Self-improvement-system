# PC・iPhone・iPadの私用接続

PCを同期先にして、Tailscaleの私用HTTPS接続でiPhone/iPadから利用する構成です。ChatGPTや公開サーバーへの配置は不要です。Tailscaleの個人向け無料枠を想定しています。サービスの料金・枠は変更される場合があります。

1. PCとiPhone/iPadにTailscaleを入れ、同じアカウントで接続します。TailscaleのHTTPSが初回に無効な場合は、表示される管理画面で有効にします。
2. 接続用ZIPを展開し、START-HERE.vbsを開いて、今使っているFocusフォルダーを選びます。更新と接続準備を続けて行います。Tailscale未導入・未ログイン・HTTPS未設定なら準備の案内が開きます。準備後は同じファイルを再実行できます。
3. PCのFocusが「同期済み」になったら、PCに表示される案内のQRをiPhoneとiPadのそれぞれで開きます。同期キーはURLのフラグメントから端末に取り込み、表示URLから取り除きます。キーをサーバーのURLログへ送りません。
4. Safariで「共有」→「ホーム画面に追加」。ホーム画面側の保存領域で未接続なら、PCの案内から同じキーを接続してください。
5. PC・iPhone・iPadでタスクと進行中の計測が同じか確認します。初回はPC側の同期が完了してからiPhoneを開きます。

PCの電源・ネットワークとTailscaleが必要です。PCがスリープ中は同期できません。スマートフォンの既存データは端末内で使え、接続後に統合します。PCをスリープさせない設定へ自動変更はしません。

セットアップは既存Serveを調べ、443または8443の空いたHTTPSポートを使います。他のServeをリセット・上書きせず、インターネットへ公開するFunnelは有効にしません。起動時にFocusの同期サーバーだけを起動するショートカットを追加します。

`focus-data/personal/local-network.json` に許可する私用HTTPS接続先、`phone-setup.html` にQRと同期キーを保存します。これらは個人用で共有禁止です。ブラウザデータを消す前はJSONを書き出してください。JSON控えの自動保存はPCの127.0.0.1側のみです。スマートフォンからPCへは暗号化同期します。

ライブのTailscale設定・iPhone実機確認は実施していません。サーバー側の接続先・認証検証とセットアップ処理は模擬接続で検証しています。
