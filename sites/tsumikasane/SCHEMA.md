# 持ち出せるデータ形式（バージョン2）

「全データJSON」は、アプリ内の全記録を構造化したJSONです。クラウドの保存状態やアプリの利用契約がなくてもファイルを読み出せます。バージョン1のJSONは、読み込み時に互換変換します。

| キー | 内容 |
| --- | --- |
| `version` | `2` |
| `tasks` | 現在のタスク。ID、名前、分野、期限、見積分、状態、完了日、希望時間帯、メモ。 |
| `events` | 予定。ID、タスクID、日付、日本時間の開始・終了、メモ、外部UID。 |
| `logs` | 実行記録。ID、日付、実行分、名前、メモ。Notionからの記録は元の開始・終了日時も保持。 |
| `reflections` | 日本時間の日付をキーとする振り返り文章。 |
| `history` | タスクの作成・編集・完了・取り消し・アーカイブ・復元・取り込み。操作時のタスクのスナップショットを保持。 |
| `archive` | `tasks`・`events`・`logs` のアーカイブ。`archivedAt`はアーカイブした日時。 |
| `sourceTables` | Notionの元CSVとページ本文。元の列名と値を配列として保持。 |

## 日時と精度

- `date`・`due`・`doneAt` は `YYYY-MM-DD` の日本時間の日付。
- `occurredAt`・`completedAt`・`updatedAt`・`startedAt`・`endedAt` は分かる場合にISO 8601のUTC日時。
- 過去の完了記録で日付しか分からない場合、`occurredAt`は`null`、`date`だけを保存します。日時不明の記録に仮の時刻は付けません。
- 完了の取り消しは、以前の完了履歴を消しません。現在の達成状況はタスクの`done`、過去の行動は`history`で区別します。

## IDと元データ

アプリのIDは移行先で照合するキーとして使えます。NotionのページIDや生成キーから安定したIDを作り、同じZIPの再取り込みによる重複を防ぎます。`sourceProperties`には対応元のプロパティを保持します。未知の列や目標・健康なども`sourceTables`からCSVとして書き出せます。

## クラウド保存

Sitesが認証したユーザーIDごとにD1へ保存します。保存はリビジョン番号で比較し、別端末の内容を黙って上書きしません。JSONは小分けで保存してUnicodeを保ち、現在とひとつ前のスナップショットを保持します。通信できない間の控えは端末内に残し、接続が戻ったら保存を試みます。

データの独立した控えとしてJSON・CSVを書き出せます。JSONの復元やNotionの取り込み前には、現在のデータのダウンロードを行います。
