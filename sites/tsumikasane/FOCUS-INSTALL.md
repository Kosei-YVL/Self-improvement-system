# Focus — Windows / iPhone / iPad

Windowsは配布の `Focus-Setup-20261101-1-x64.exe` からインストールします。Windows 10以降の64ビット版が対象です。Node.jsの別途インストールは不要です。EdgeまたはChromeのアプリ用ウィンドウで開きます。ChatGPTのアカウント・接続は使いません。

## Windowsで使う

1. Focusの画面を閉じます。旧 `START-WINDOWS.cmd` の黒いウィンドウから起動中なら、それも閉じます。
2. インストーラーを開きます。既存版を更新するときは、`server.mjs` と `app-assets.json` が入っている現在のFocusフォルダーを選択してください。親に `personal` がある構成では、その `personal` を選びます。
3. デスクトップまたはスタートメニューのFocusを開きます。

インストーラーは管理者権限を要求しないユーザー単位のインストールです。自己署名で警告を隠すことはしていません。この個人テスト版には商用コード署名がないため、Windowsが未認識のアプリと表示する場合があります。

起動先は既存版と同じ `http://127.0.0.1:4545/focus.html`。同じブラウザープロファイルの端末内データを引き継ぎます。別ブラウザーを使用した場合は同じ同期キーで接続するか、JSONを復元してください。旧サーバーが別フォルダーから起動中の場合は、新しい空の環境を並行起動せず、既存版のフォルダーを選び直してください。

Windowsログイン時は同期用サーバーを非表示で起動します。停止するときはスタートメニューの「Focusを終了」。自動起動が不要ならWindowsのスタートアップから「Focus Sync」を無効にできます。

## iPhone・iPadで使う

1. スタートメニューの「Focus → iPhone・iPadを接続」を開きます。
2. 初回はWindows・iPhone・iPadにTailscaleをインストールし、同じ個人アカウントで接続します。再び同じメニューを開くと接続用のQRを表示します。
3. PCで同期済みを確認してからQRを各端末のSafariで開き、共有 → ホーム画面に追加。
4. ホーム画面のFocusを開き、設定 → 連携で同期済みを確認します。未接続ならQRと同じ案内に表示される同期キーを設定します。

これは無料でホーム画面に追加できるPWAです。App Store版・署名済みのIPAではありません。初回読み込み後は端末内でオフライン動作します。端末をまたぐ反映とGoogleカレンダーの取得には通信が必要です。PC停止・スリープ中は各端末へ保存し、PCに再接続すると同期します。計測の経過時間は再表示時に復元しますが、Safari終了中の確実な時刻通知・音は提供しません。

## データと更新

- 新規インストールのサーバーデータは `%LOCALAPPDATA%\Focus\data\personal`。ブラウザー側はIndexedDBに保存します。
- 既存版は元の `focus-data\personal` などの保存先を継続します。アプリフォルダーの `installation.json` に保存先だけを記載します。
- 既存コードの更新前に、サーバーデータと設定の控えを保存します。同期キーやGoogle設定を初期化しません。
- アンインストールはアプリとショートカットを削除し、記録・JSONバックアップ・`installation.json`・ブラウザーのデータは残します。
- 設定 → データ → JSON または移行用ZIPで、記録・元データを取り出せます。移行用ZIPにはCSVと予定のICSも含みます。
- 個人用インストーラーと個人用ZIPには、前回と同じNotion移行データを含みます。同じ移行を繰り返しても重複登録しません。他の人に共有しないでください。

## 表示

設定 → 表示 → スキンの「一覧」から20種類を比較できます。全スキンで操作と配置は共通。ダーク・ライト・端末に合わせる表示、スクロール連動の反射、動作軽減に対応します。Frutiger Aero、Decadence、Opiumcore、Digicore、Glitchcoreなどの装飾は静止レイヤーを中心に使います。初期表示はMinimal Basic、ロゴは同心円です。

実機Windows・iPhone・iPadの最終確認、本人のTailscaleログイン、Google認可はこの作業環境からは実行できません。自動テストの内容と未確認事項は同梱の検証結果に記載します。
