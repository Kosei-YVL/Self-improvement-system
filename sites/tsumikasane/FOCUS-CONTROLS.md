# Focus 2026.11.01 — 小画面表示アイコン・ボタン配置

Windowsは `Focus-Setup-20261101-x64.exe` を開き、現在のFocusフォルダーへ更新します。記録・同期キー・Google設定は保持します。ZIPの場合は展開して `UPDATE-FOCUS.vbs` を開きます。以前の配布物は別ファイルとして保持しています。

iPhone・iPadはPC更新後に接続し、Focusの設定 → 使い方 →「新しいバージョンを開く」を選びます。ボタンが出なければ閉じて再度開いてください。末尾の **Focus 2026.11.01** が目印です。

- 計測中の「小窓」という文字を、外枠の右下に小さい画面があるPicture-in-Pictureアイコンに変更しました。表示名は省き、読み上げ名とツールチップは保持しています。クリック・キーボードで従来と同じ実際の小画面を開けます。PCのChrome・Edge向けで、非対応ブラウザーは通常の計測画面を使います。
- 記録画面の前後矢印は、日付ラベルを含む全体の中心ではなく日付入力ボタンに合わせました。
- タスクカードの「設定」は見出しの先頭行と高さを揃えました。
- 編集画面の保存・配置ボタンは操作列の最後へ統一しました。PCは右下、狭いスマホ画面では下側の横幅いっぱいを使います。表示順とキーボードの移動順も一致させています。
- 長い設定画面をスクロールしても「閉じる」を見失わないように、見出しと設定タブを重ならない位置へ固定しました。

記録・予定・タイマーの仕様は変更していません。タスクからの日程へのドラッグ、0〜24時表示、現在時刻ライン、領域別の即時スクロール、追加記録と過去の実績保持、Google連携、音なし通知を引き継ぎます。

合成データでPC・iPad相当・スマホ・横向き表示を確認しました。ボタンのカード外へのはみ出し、中央を他の要素に遮られる状態、矢印と日付入力の高さ、保存ボタンの順序、スクロール後の閉じる操作を検証しました。実際のDocument Picture-in-Picture APIと更新時のデータ保持も確認しました。詳細はvalidation-controlsと別配布の検証JSONに残します。実機のWindows・iPhone・iPadの表示・操作感は未確認です。
