# 積みかさね — 端末内テスト版

タスク・予定・作業ログ・達成履歴・Notionから取り込んだ元データを、このブラウザのIndexedDBに保存します。ChatGPTへのログインやクラウド契約は不要です。オフラインでも入力・閲覧・JSON/CSVの書き出しを行えます。公開・端末間同期・自動バックアップは行いません。

この版には、データを受け取るAPIやサーバー側データベースがありません。外部フォントも読み込みません。起動用サーバーが配るのは画面用ファイルだけで、記録は送信しません。

## Windowsでテストする

1. Node.js 24をインストールします。
2. ZIPを解凍し、`START-WINDOWS.cmd` をダブルクリックします。
3. EdgeまたはChromeで `http://127.0.0.1:4545` を開きます。ログインやパスワードの設定はありません。
4. タスクを作り、「この端末に保存済み」を確認します。
5. 初回に画面用ファイルの準備が完了すると、オフラインで開き直せます。Edgeの「このサイトをアプリとしてインストール」からデスクトップに追加できます。

毎回同じURL・同じブラウザ・同じブラウザプロファイルで開いてください。`localhost`、別のポート、別のブラウザでは保存場所が異なります。初回の画面読み込みやアプリ更新時は、起動用サーバーを動かしてください。保存済みの画面・データは、サーバーを止めてもオフラインで利用できます。

起動用サーバーはPC内からだけアクセスできます。インターネットや同じWi-Fi上の別端末には公開しません。PCのファイルにSQLiteデータベースを作る従来の独立版とは別の構成です。

## 保存場所とバックアップ

- 記録：このURL・ブラウザプロファイル専用のIndexedDB。アプリフォルダーではなく、ブラウザが端末内で管理する領域です。
- 画面：Service Workerのオフライン用キャッシュ。
- 表示設定：端末内のブラウザ保存領域。
- バックアップ：「履歴・データ」→「全データJSON」で、自分が選んだファイルへ書き出します。復元は「データと設定」→「全データを復元する」です。

既存の公開版・独立版から移すときは、その版で全データJSONを書き出してから、このテスト版へ復元してください。元のデータは自動で移動・削除しません。

JSONをiCloud DriveやGoogle Driveのフォルダーへ自分で保存した場合は、そのサービス側の同期対象になります。アプリ自体がDriveやiCloudへ送信することはありません。

## 保存の注意点

ブラウザのサイトデータ削除、プロファイル削除、端末の故障・紛失で、端末内の記録も失われます。プライベートブラウズを避け、定期的にJSONを書き出してください。「保存とバックアップ」から保存領域の保持をリクエストできますが、データ削除の操作を防ぐものではありません。

この版は記録の暗号化やアプリ独自のロックを追加しません。端末とブラウザプロファイルを開ける人は記録を閲覧できます。端末のロックを使い、バックアップの保管先も自分で管理してください。

複数の画面から同じデータを変更すると、上書きを防いで保存を止めます。表示中の内容をJSONへ控えてから画面を開き直してください。

## iPhoneについて

iPhoneでもIndexedDBへ端末内保存できます。データはPCとは別になり、自動同期しません。JSONファイルを使って手動で移せます。

Safariからホーム画面へ追加してオフラインで起動するには、最初にアプリの画面用ファイルをHTTPSで読み込む導入方法が必要です。PCの `127.0.0.1` はiPhoneから開けません。このZIPをiPhoneの「ファイル」で開くだけでは、ホーム画面用アプリの導入は完了しません。

今回は公開を見送り、Windowsで試せる形を用意しています。`web/` に含む画面用ファイルは、後で本人用HTTPS環境からiPhoneへ導入する際に利用できます。HTTPSで配る場合も、記録の保存先は端末内のままです。
