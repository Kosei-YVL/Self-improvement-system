# Focus — 2026年10月29日 更新・検証

## 今回の変更

- Windows用64ビットセットアップと起動用EXEを作成。Node.js 24.19.0を同梱し、管理者権限・Node.jsの別途導入は不要。通常のEdge/Chromeプロファイルと既存の起動URLを使います。
- iPhone・iPadはSafariからホーム画面へ追加するPWA。初回接続をWindowsのスタートメニュー「Focus → iPhone・iPadを接続」へ集約しました。
- 20スキンを追加。Minimal Basic / Glass / Chrome / Garnet / Frutiger Aero / Decadence / Opiumcore / Digicore / Glitchcore / Monochrome / Ivory / Slate / Midnight / Forest / Sandstone / Cobalt / Aurora / Dusk / Sakura / Terminal。
- スキン一覧で比較し、タップで即反映。全スキンで操作・配置・記録形式を共通にし、端末ごとの表示設定として保存します。
- ガラスの反射、ボタンの質感、タッチ操作の押しやすさ、iPhoneの画面端の余白を調整。装飾は静止レイヤーが中心で、未操作時に装飾アニメーションを回しません。
- 計測の取消に10秒間の「元に戻す」。復帰は一時停止状態で、取消中の時間を作業に加算しません。
- 完了のチェックはIndexedDBへの保存成功後に表示。保存が失敗した場合は成功の演出を出さず、保持した記録を書き出し・再保存できます。
- 開始ボタンの二重押しで、同じ位置の完了ボタンまで押してしまう問題を再現して修正。開始後600ミリ秒だけ完了操作を抑止し、PC・スマホとも誤記録を1件から0件に減らしました。

Windows EXEの検証はLinux上のWindows互換環境です。物理Windows、iPhone・iPadのSafari実機、本人のTailscale接続・Google認可は未確認です。幅の検証は記載したサンプル範囲で、すべての端末・倍率の保証ではありません。

## 利用上の条件

PCが起動してTailscaleでつながっている間に端末間同期します。PC停止中も読み込んだ端末内では作業・記録でき、再接続後に反映します。Safari終了中の確実な音・時刻通知は未対応で、再表示時に経過時間を復元します。

この個人テスト用インストーラーは未署名です。Windowsの認識確認が表示される場合があります。個人用の配布物にはNotion移行データが含まれるため、第三者へ共有しないでください。ユーザーのPCへの適用・各端末への追加は、このチャットからは実行していません。

導入手順は [FOCUS-INSTALL.md](FOCUS-INSTALL.md)。検証結果のJSONと、今回のソースを更新用ZIPに含めています。従来の3回分の改善成果物も保持しています。
